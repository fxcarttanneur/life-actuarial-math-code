# Browser notebooks (JupyterLite)

This folder turns the companion code into a JupyterLite site: Jupyter running entirely in the
reader's browser through Pyodide (Python compiled to WebAssembly). No install, account or server.

Live site: <https://fxcarttanneur.github.io/life-actuarial-math-code/>

## Contents

| Notebook | Book chapters | Module |
|---|---|---|

The notebooks are generated by `make_notebooks.py`, which also copies `src/`, `data/` and `tests/`
into `content/` unchanged. Edit that script (not the generated `.ipynb` files) to change them.

## Build

macOS / Linux:

```bash
./lite/build.sh
```

Windows (PowerShell):

```powershell
python -m venv lite\.venv
lite\.venv\Scripts\pip install -r lite\requirements.txt
lite\.venv\Scripts\python lite\make_notebooks.py
cd lite; .venv\Scripts\jupyter lite build --contents content --output-dir dist
```

`./lite/build.sh --offline <pyodide-tarball>` bundles the Python runtime so the site works without
the jsDelivr CDN (adds several hundred MB).

## Serve locally

```bash
python3 -m http.server -d lite/dist 8000
```

Then open <http://localhost:8000/>.

## Deploy

Every push to `main` runs `.github/workflows/deploy-lite.yml`, which builds the site and publishes
it on GitHub Pages. One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
